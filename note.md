### pola pikir software engineer
problem understanding 
  memahami permasalahan yang terjadi
logical thingking 
  menggunakan hubungan, sebab, akibat, aturan, batasan, dan kemungkinan yang harus ditangani sistem
promblen solving
  memecahkan masalah besar menjadi bagian kecil, memilih algorithm atau pendekatan, kemudian menguji apakah solusi benar
Implementation 
  mengimplementasikan solusi dengan struktur yang jelas, aman, efesien, dan mudah dikembangkan

### Version control
pengertian : sistem yang mencatat setiap perubahan file (bisa dilihat, dibandingkan, dikembalikan)
- riwayat perubahan
- backup
- collaboration
- rollback

why version control penting
tanpa pengelola versi yang baik, perubahan ketiga pengembang dapat saling menimpam dan sulit lah pokoknya

solo vs team
solo dev : seperti checkpoint di game
          alat penyelamat progress kerja
team : kolaborasi 
      alat supaya kerja bareng tidak berantakan

### git vs github
istilah secara umum yang sering digunakan

1. repo
  *folder*
2. commit
  *simpan perubahan lenhkap dengan catatan*
3. push
  *kirim update ke github*
4. pull
  *ambil update dari github*
5. clone
  *menyalin repo github*
6. branch
  *jalur kerja terpisah untuk coba coba*
7. pull req
  *menyesuaikan perubahan agar ditinjau dan digabungkan*
8. confliot
  *kondisi perbedaan pada bagian yang sama tidak dapat digabungkan decara otomatis*
9. merge
  *menggabungkan history commit dari satu branch ke branch lainnya*

alur kerja git
working directory (edit di sini) ->> staging area(siap disimpan) ->> local repo(disimpan di laptop) ->> remote(github)
